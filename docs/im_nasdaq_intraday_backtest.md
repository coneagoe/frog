# 纳斯达克下跌触发 IM 日内开空回测

> 统计目的: 验证“前一晚纳斯达克大跌后，次日开盘做空 IM，中午后平仓”的日内策略是否有优势。
> 数据区间: IM 上市后至 2026-06-10；重点复测 2024-01-01 后。
> 数据源: 纳斯达克日线使用 AkShare；IM 主连 1 分钟线使用 TqSdk `DataDownloader`。
> 交易口径: 仅做日内空单，不隔夜；结果为单手 IM 毛收益，未扣手续费、滑点和冲击成本。

## 策略假设

1. 计算前一交易日纳斯达克收盘价相对前收盘价的涨跌幅。
2. 若纳斯达克跌幅 `<= -1%`，则次日触发 IM 日内空头信号。
3. 使用 IM 主连 `KQ.m@CFFEX.IM` 的 1 分钟线。
4. 分别测试两种开仓口径：
   - `09:31 open` 开空：避开开盘第一分钟噪音。
   - `09:30 open` 直接开空：测试更激进的开盘即入场版本。
5. 分别测试两种平仓口径：
   - `14:00 close` 平仓。
   - `14:30 close` 平仓。

收益计算：

```text
空单点数收益 = 开仓价 - 平仓价
单手毛收益 = 空单点数收益 × 200
```

## 初步结论

1. **纳指跌幅 `<= -1%` 后次日开盘直接空 IM 没有正期望。**
   - 无论 09:30 还是 09:31 开空，14:00 / 14:30 平仓整体均为负收益。
2. **09:30 直接开空整体比 09:31 更差。**
   - 开盘第一分钟可能包含低开后的快速反抽和成交噪音，直接追空容易吃亏。
3. **2024 年后结果没有改善。**
   - 2024 后样本中，`<= -1%` 版本 14:00 和 14:30 均为负收益。
4. **更强阈值存在研究价值，但样本不足。**
   - 09:31 开空、纳指跌幅 `<= -2%`、14:00 平仓在 2024 后均值为 `+392 元/手`，但胜率仅 `45.7%`，稳定性不足。
   - `<= -4%` 样本仅 4~5 笔，结果受极少数事件影响，不宜直接作为策略依据。

## 跳空与日内走势拆解

为验证“日线跟随纳斯达克下跌，但日内开空亏损可能来自跳空低开后反抽”的假设，将事件日收益拆成三段：

```text
前收 → 09:30 open：隔夜跳空
09:30 open → 14:00/14:30：日内走势
前收 → 当日收盘：日线涨跌
```

拆解结果文件：

```text

```

| 指标 | 结果 |
|------|-----:|
| 日线收盘 vs 前收下跌比例 | 55.7% |
| 09:30 跳空低开比例 | 77.2% |

| 09:30 → 14:00 平均涨跌 | +0.04% |
| 09:30 → 14:30 平均涨跌 | +0.07% |

纳指下跌后的 IM 弱势，较多已经体现在开盘低开里；开盘后并没有继续下跌，反而略偏反弹。

### 按 09:30 缺口分组

#### 全样本

| 开盘缺口 | 样本 | 日线下跌率 | 14:00 空单胜率 | 14:00 均值 |
|----------|-----:|-----------:|---------------:|-----------:|
| gap <= -1% | 16 | 81.2% | 25.0% | -6,163 元 |
| -1% < gap < 0 | 106 | 56.6% | 46.2% | -692 元 |
| gap >= 0 | 36 | 41.7% | 52.8% | +3,011 元 |

#### 2024-01-01 后

| 开盘缺口 | 样本 | 日线下跌率 | 14:00 空单胜率 | 14:00 均值 |
|----------|-----:|-----------:|---------------:|-----------:|
| gap <= -1% | 14 | 85.7% | 28.6% | -4,829 元 |
| -1% < gap < 0 | 51 | 56.9% | 43.1% | -1,882 元 |
| gap >= 0 | 17 | 35.3% | 58.8% | +6,739 元 |

这个分组支持一个关键判断：**低开越多，越不适合开盘追空**。当 `gap <= -1%` 时，日线大概率仍是下跌的，但 09:30 开空胜率反而很低，因为主要跌幅已经通过隔夜缺口释放，日内更容易反抽。

因此，纳指下跌信号不应直接等价为“开盘追空”。更值得继续研究的方向是：

```text
纳指大跌 + IM 未充分低开 / 小幅低开 / 高开
→ 外盘利空可能尚未完全 price in
→ 日内空头信号可能更有效
```

## 后续可研究方向

1. 加入 IM 当日低开幅度过滤：避免已经充分低开后追空。
2. 等待 09:45 或 10:00 弱势确认后再入场，而非开盘直接空。
3. 将纳指跌幅与 A 股开盘缺口联合分组，区分“低开继续弱”和“低开反抽”。
4. 加入手续费、滑点和开盘冲击成本后重新评估。
5. 对比做空 IM 与降低多头仓位/风险过滤器两种用途，避免把弱预测信号硬做成裸空策略。
